# Asset provenance

- `app-icon.ico` / `app-icon.png` — original map-pin icon created for this
  project (2026-07-16), regenerated 2026-08-01 by the now-committed
  `tools/make_app_icon.py` (#438). The `.ico` is multi-resolution 16–256 px;
  the `.png` is the 1024 px master the macOS release workflow renders the
  `.icns` from. Regenerate both with `uv run python tools/make_app_icon.py`.
- `home-background.png` — AI-generated image (Grok, xAI) supplied by the
  project maintainer, 2026-07-16. Generic drone over a mountain landscape;
  not a photograph and not DJI marketing material.
